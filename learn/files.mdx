title: 'File uploads'
description: 'Upload source files for data extraction.'
---

Lasso accepts a variety of file formats as source data for extraction. Upload files first, then reference them by ID when creating a table.

## Supported formats

| Format | Extensions | Notes |
|---|---|---|
| PDF | `.pdf` | Scanned and text-based PDFs are both supported. |
| Spreadsheets | `.xlsx`, `.xls`, `.xlsm`, `.csv` | Each sheet or file is parsed for product data. |
| Images | `.jpg`, `.jpeg`, `.png`, `.webp` | OCR extracts text from images. |
| Documents | `.docx`, `.pptx` | Word and PowerPoint documents are parsed for content. |
| Text and markup | `.txt`, `.xml`, `.html`, `.htm` | Text content is decoded and parsed. |

## Upload flow

<Steps>
  <Step title="Upload the file">
    Send the file as `multipart/form-data` to `POST /files`. The upload endpoint accepts files up to 1 GB.
  </Step>
  <Step title="Get the file ID">
    The response includes an `id` field. Store this for the next step.
  </Step>
  <Step title="Create a table">
    Pass the file ID in the `file_ids` array when creating a table.
  </Step>
</Steps>

## Extraction limits

Creating a table applies stricter source limits than uploading a file:

| Source type | Maximum size |
|---|---:|
| PPTX | 20 MB |
| DOCX | 50 MB |
| XML, HTML, HTM, or TXT | 64 MB |
| JPG, JPEG, PNG, or WebP | 100 MB |
| Other file types | 256 MB |
| All selected files combined | 512 MB |

The API rejects duplicate source file names in the same table request.

## Example

<CodeGroup>
```typescript TypeScript
const file = new File([buffer], "catalog.pdf", { type: "application/pdf" });
const uploaded = await client.files.upload(file, "catalog.pdf");

const table = await client.tables.create({
  schema_id: "9e1c77dd-8f10-41ca-bfe8-e672b89692d1",
  name: "My Catalog",
  file_ids: [uploaded.id],
});
```

```python Python
uploaded = client.files.upload("/path/to/catalog.pdf")

table = client.tables.create(
    schema_id="9e1c77dd-8f10-41ca-bfe8-e672b89692d1",
    name="My Catalog",
    file_ids=[uploaded["id"]],
)
```
</CodeGroup>

## Alternative sources

If you do not want to upload a file, pass raw text in `source_text`. For a remote file, download it first and upload it through `POST /files`; direct `file_urls` ingestion is not supported by the extraction worker.

## Managing files

Files can be listed and deleted through the [Files API](/api-reference/files/list). Deleting a file does not affect tables that were already created from it.
