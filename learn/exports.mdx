Once your table is complete, you can export the data in several formats.

## Available formats

| Format | Description | Use case |
|---|---|---|
| **JSON** | Array of row objects | Programmatic processing, API integrations |
| **CSV** | Semicolon-delimited file | Spreadsheet import, data analysis |
| **XLSX** | Excel spreadsheet | Business users, reporting |
| **Images** | ZIP archive of all images | Asset management, media libraries |

## Exporting data

The SDK's JSON helper returns parsed data. With the TypeScript SDK v0.2, fetch CSV, XLSX, and image ZIP exports from the endpoint so you can read the raw response body.

<CodeGroup>
```typescript TypeScript
import { writeFile } from "node:fs/promises";

// JSON returns parsed data through the SDK.
const data = await client.export.json("d2b3dbe0-c77d-40d8-a5d2-480722489c64");

async function fetchExport(format: "csv" | "xlsx" | "images") {
  const url = new URL(
    "https://app.productlasso.com/api/v1/tables/d2b3dbe0-c77d-40d8-a5d2-480722489c64/export",
  );
  url.searchParams.set("format", format);

  const response = await fetch(url, {
    headers: { Authorization: `Bearer ${process.env.LASSO_API_KEY}` },
  });
  if (!response.ok) throw new Error(await response.text());
  return response;
}

const csv = await (await fetchExport("csv")).text();
const xlsx = Buffer.from(await (await fetchExport("xlsx")).arrayBuffer());
const images = Buffer.from(await (await fetchExport("images")).arrayBuffer());

await writeFile("export.xlsx", xlsx);
await writeFile("images.zip", images);
```

```python Python
import httpx
import os

# JSON -- returns list of dicts
data = client.export.json("d2b3dbe0-c77d-40d8-a5d2-480722489c64")

# Fetch CSV as text from the endpoint.
response = httpx.get(
    "https://app.productlasso.com/api/v1/tables/d2b3dbe0-c77d-40d8-a5d2-480722489c64/export",
    params={"format": "csv"},
    headers={"Authorization": f"Bearer {os.environ['LASSO_API_KEY']}"},
)
response.raise_for_status()
csv = response.text

# XLSX -- save directly to file
client.export.xlsx("d2b3dbe0-c77d-40d8-a5d2-480722489c64", path="export.xlsx")

# Images -- save ZIP to file
client.export.images("d2b3dbe0-c77d-40d8-a5d2-480722489c64", path="images.zip")
```
</CodeGroup>

## Selecting columns

By default, all columns are exported. To export only specific columns, pass a comma-separated list of column keys:

<CodeGroup>
```typescript TypeScript
const data = await client.export.json("d2b3dbe0-c77d-40d8-a5d2-480722489c64", {
  columns: "product_name,price,image_url",
});
```

```python Python
data = client.export.json("d2b3dbe0-c77d-40d8-a5d2-480722489c64", columns="product_name,price,image_url")
```
</CodeGroup>

## Pandas integration (Python)

The Python SDK includes a helper to load all rows as a pandas DataFrame:

```python
df = client.tables.results_as_dataframe("d2b3dbe0-c77d-40d8-a5d2-480722489c64")

# Filter, analyze, or export further
expensive = df[df["price"] > 100]
df.to_csv("products.csv", index=False)
```

This fetches all pages automatically and returns a ready-to-use DataFrame.

## Template descriptions

Table CSV, XLSX, and JSON exports render structured template content as HTML. Choose the export appearance in the column settings: visual templates support classes, inline styles, or unstyled HTML; coded templates support HTML + CSS, classes, or unstyled HTML. Standard exports remove scripts and event handlers.

XLSX allows at most 32,767 characters per cell. Use CSV or JSON for longer descriptions; XLSX returns an error instead of truncating content. Catalog CSV descriptions are plain text.

Verify the actual storefront import before publishing. See [Content templates](/learn/content-templates) for the creation workflow, HTML classes, and responsive CSS.
