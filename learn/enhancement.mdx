Enhancement lets you use AI to fill in, improve, or transform column values after extraction. This is useful for generating descriptions, translating content, or enriching data with web-sourced information.

## How enhancement works

1. **Select rows and a column** -- Choose which rows to enhance and which column to fill.
2. **Write a prompt** -- Describe what the AI should generate, using context from other columns.
3. **AI processes each row** -- The model reads the row's existing data and generates a value.
4. **Results are written back** -- Enhanced values replace or fill the target column.

## Enhancement types

### Content generation

Generate new content based on existing data:

```text
"Write a compelling product description from {{product_name}} and {{specifications}}."
```

### Translation

Translate content to another language, optionally using your glossary:

```text
"Translate {{description}} to German."
```

Set `target_language` and `use_glossary: true` to apply your glossary terms during translation.

### Web research

Enable `web_search: true` to let the AI search the web for additional information:

```text
"Find the current retail price for this product from major retailers."
```

## Single column vs bulk

- **Single column** -- Enhance one column across multiple rows. Use [`POST /tables/{table_id}/enhance`](/api-reference/enhance/run).
- **Bulk** -- Enhance multiple columns of a single row at once. Use [`POST /tables/{table_id}/enhance/bulk`](/api-reference/enhance/bulk).

## Tracking progress

Enhancement runs asynchronously. Check progress with:

<CodeGroup>
```typescript TypeScript
const status = await client.enhance.status("d2b3dbe0-c77d-40d8-a5d2-480722489c64");

for (const [column, stats] of Object.entries(status.columns)) {
  console.log(`${column}: ${stats.completed}/${stats.total} done`);
}
```

```python Python
status = client.enhance.status("d2b3dbe0-c77d-40d8-a5d2-480722489c64")

for column, stats in status["columns"].items():
    print(f"{column}: {stats['completed']}/{stats['total']} done")
```
</CodeGroup>

## Credits

Each enhancement consumes credits. Regular single-column enhancement costs 2 credits per row; regular bulk enhancement costs 0.5 credits per column. Gallery Max image columns use a separate 16-credit rate, which the current bulk estimate does not reflect. Check your balance via the [Credits API](/api-reference/credits/balance).

## Traces

Recorded traces can include the prompt, configured model, confidence score, tool calls, sources, response text, and a summarized thought. They do not expose private chain of thought. See [Row traces](/api-reference/rows/traces) for details.
