openapi: "openapi.yaml GET /tables/{table_id}/rows"
---

## Usage notes

This endpoint is available only after the table reaches `completed`. A table that is still processing returns `409`.

Each row stores extracted values in `data`, keyed by the table column key. Use `sort_by` with a column key and `sort_order` with `asc` or `desc`.
