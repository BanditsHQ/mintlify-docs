---
title: "Delete multiple rows"
description: "Delete multiple rows from a Lasso extraction table in one API request by sending the IDs of the rows you want to remove."
openapi: "openapi.yaml POST /tables/{table_id}/rows/bulk-delete"
---

The handler deletes rows whose IDs match the table. Unknown IDs and IDs from another table are ignored. `deleted_count` reports the number actually removed.
