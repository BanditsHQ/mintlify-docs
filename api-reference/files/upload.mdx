---

## Usage notes

- Send the file as `multipart/form-data` in the `file` field.
- The upload endpoint accepts a file up to 1 GB. Extraction applies stricter format-specific limits when you later create a table.
- Save the returned `id`. Pass it in `file_ids` when you call `POST /tables`.

An uploaded file is private to your company. Deleting the upload does not delete tables that already imported it.
