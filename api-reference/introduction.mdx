The Lasso API provides company-scoped access to product search and enrichment, extraction tables, Shared Attributes, Product Schemas, Catalog products, webhooks, credits, and product analytics.

## Base URL

```text
https://app.productlasso.com/api/v1
```

Send HTTPS requests to this URL. Most responses use JSON. File uploads use `multipart/form-data`, and export endpoints can return JSON, CSV, XLSX, or ZIP content.

## Authentication

Send your API key as a bearer token on every request:

```http
Authorization: Bearer lasso_your_api_key
```

API keys start with `lasso_` and grant access to one company. See [Authentication](/api-reference/authentication) for creation and storage guidance.

## API contract

The [OpenAPI 3.1 contract](/openapi.yaml) contains all 59 public operations in the current API, including request schemas, response schemas, errors, and examples. The endpoint pages in this reference are generated from that contract.

The main resource groups are:

- Search and enrichment
- Tables, rows, enhancements, files, and exports
- Shared Attributes and Product Schemas
- Catalog products and Catalog webhooks
- Credits and product analytics

## Request example

```bash
curl --request GET \
  --url "https://app.productlasso.com/api/v1/tables?page=1&limit=25" \
  --header "Authorization: Bearer lasso_your_api_key"
```

## Success responses

| Status | Meaning |
| --- | --- |
| `200` | The request succeeded. |
| `201` | A resource was created. |
| `202` | Asynchronous processing was accepted. |
| `204` | The request succeeded without a response body. |

See [Errors](/api-reference/errors) for the error envelope and retry metadata.

## Pagination

The API uses page-based, cursor-based, and offset-based pagination depending on the resource. Do not assume that every list endpoint accepts `page` and `limit`. See [Pagination](/api-reference/pagination) and the endpoint contract.
