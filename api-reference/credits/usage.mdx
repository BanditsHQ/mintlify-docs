## Usage notes

`from` and `to` are date filters. `service` accepts the exact public service values shown in the parameter schema. `total_used` is calculated over the full filtered period, not only the current page.

<Note>
  In Python SDK `0.2`, pass the reserved query name with `client.credits.usage(**{"from": "2026-08-01", "to": "2026-08-31"})`. The convenience name `from_` is not translated to `from`.
</Note>
