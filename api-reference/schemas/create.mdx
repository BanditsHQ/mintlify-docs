## Usage notes

- A Product Schema needs a name and at least one column.
- To attach an existing company Attribute, send its `attribute_id` with `kind: attribute`. Its key and type must match.
- To create a table-local helper, send `kind: helper` and omit `attribute_id`.
- If you omit both identity fields, Lasso preserves the legacy behavior and creates or attaches the company Attribute for the column key.

Retain the server-issued column `id` when you later replace the full `columns` array with `PUT /schemas/{schema_id}`.
