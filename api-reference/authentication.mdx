---
title: "Authentication"
description: "Authenticate Lasso API requests with a company-scoped bearer key."
---

Every public API operation requires an API key in the `Authorization` header.

```http
Authorization: Bearer lasso_your_api_key
```

Keys start with `lasso_`. The current key format contains 32 random bytes encoded as 64 hexadecimal characters after the prefix.

## Create a key

Open the [Lasso dashboard](https://app.productlasso.com), go to **Settings** > **API Keys**, and create a key. You need the **Manage API keys** permission (`developer.manage_api_keys`).

<Warning>
  The raw key is returned once. Store it in a secret manager or environment variable. If you lose it, deactivate the key and create another one.
</Warning>

## Company scope

Each API key belongs to one company. The server derives the company from the key; requests cannot select another tenant. Use a separate key for each environment or integration.

## Example

```bash
curl --request GET \
  --url "https://app.productlasso.com/api/v1/credits/balance" \
  --header "Authorization: Bearer $LASSO_API_KEY"
```

## Authentication errors

A missing header, invalid prefix, unknown key, or inactive key returns `401 unauthenticated` in the standard [error envelope](/api-reference/errors).
