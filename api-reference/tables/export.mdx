## Response formats

| `format` | Content type | Response |
| --- | --- | --- |
| `csv` | `text/csv` | CSV file |
| `xlsx` | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` | Excel workbook |
| `json` | `application/json` | JSON array of row objects |
| `images` | `application/zip` | ZIP archive of exported images |

The table must be completed before export. Pass `columns` as a comma-separated list of column keys. Treat every non-JSON response as bytes and preserve the `Content-Disposition` filename when saving it.

<Warning>
  TypeScript SDK `csv`, `xlsx`, and `images` helpers and the Python SDK `csv` helper currently parse the response as JSON. Use direct HTTP for those formats. The Python `xlsx` and `images` helpers already return bytes.
</Warning>
