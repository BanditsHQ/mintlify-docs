## Usage notes

Use `status` only with the raw values returned by the API: `queued`, `queued_for_processing`, `processing`, `processing_by_worker`, `completed`, `error`, or `cancelled`.

The response is page-based. `locked: true` means another operation currently owns the table lock. Wait and retry a mutation rather than writing around the lock.
