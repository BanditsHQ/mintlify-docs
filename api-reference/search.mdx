## Usage notes

- Send either `schema_id` or `columns`, not both. Lasso uses the default Product Schema when you omit both.
- `max_results` accepts `1` through `7` and defaults to `7`.
- A search costs 5 credits, independent of the number of returned products.
- Without `webhook_url`, the request waits for a `200` response. With `webhook_url`, Lasso returns `202` and posts the completed result to your URL.

Put product filters directly in `query`, for example `Sony earbuds under $200 with USB-C charging`.
