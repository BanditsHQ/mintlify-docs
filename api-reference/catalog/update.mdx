---
title: "Update a Catalog product"
description: "Update selected values on a Catalog product and explicitly attach or detach product-only Attributes in the same request."
openapi: "openapi.yaml PATCH /catalog/{id}"
---

## Usage notes

- `attributes` is a sparse merge. Omitted existing values remain unchanged.
- Send `expected_updated_at` from your latest read to protect against stale writes.
- `attribute_extension_ids` attaches product-only Attributes. Omitting it or sending an empty array preserves existing extensions.
- Only `remove_attribute_extension_ids` detaches extensions. Detaching also removes their stored values or Relation links atomically.
- You cannot detach an Attribute owned by the base Product Schema.
