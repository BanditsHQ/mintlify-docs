---
title: "List Catalog products"
description: "Returns active Shared Attribute values from each product's base schema and its own product-only Attribute extensions."
openapi: "openapi.yaml GET /catalog"
---

## Usage notes

This endpoint uses cursor pagination, not page numbers. Pass the returned `next_cursor` unchanged to fetch the next page. A `null` cursor means the result set is complete.

The `attributes` object includes active Attributes from the product's Product Schema and any product-only `attribute_extensions`. Use `status`, `source`, `schema_id`, and `search` to narrow the result set.
