---
title: "Look up a Catalog product by Attribute value"
description: "Returns the first active product whose stored Attribute value exactly matches the supplied value."
openapi: "openapi.yaml GET /catalog/lookup"
---

## Usage notes

`key` is an Attribute storage key and `value` is an exact stored value. The endpoint searches active products and returns the first match.

Use this endpoint only when the selected Attribute is unique in your data model. For general filtering or text search, use `GET /catalog`.
