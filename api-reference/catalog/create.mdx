## Usage notes

- `schema_id` selects the product's reusable Product Schema.
- Keys in `attributes` must resolve to active Attributes in that schema or in `attribute_extension_ids`.
- `attribute_extension_ids` attaches existing company Attributes to this product only. It does not add them to the reusable Product Schema.
- Relation values and Attribute values are validated before the product is created. A validation failure creates nothing.

New API-created products use the handler's default source and lifecycle state; inspect the returned `source` and `status` instead of assuming them.
