title: "Webhooks"
description: "Choose between one-off asynchronous callbacks and managed Catalog webhook subscriptions."
---

Lasso exposes two webhook models with different delivery behavior.

## Asynchronous operation callbacks

Search, enrichment, table creation, and enhancement requests can accept a `webhook_url` where shown in their endpoint contract. These callbacks deliver the result of that operation. The table callback implementation times out each attempt after 10 seconds and retries three times after 30 seconds, 5 minutes, and 30 minutes.

Use the exact callback fields documented on the endpoint. Do not assume Catalog webhook management, delivery history, test events, or redelivery applies to one-off operation callbacks.

## Catalog webhook subscriptions

Create a managed subscription with `POST /catalog/webhooks`. It can subscribe to:

- `product.created`, `product.updated`, and `product.deleted`
- `attribute.created`, `attribute.updated`, and `attribute.deleted`

Production endpoints must use public HTTPS destinations. Redirects are not followed. Each automatic delivery makes one attempt with a 10-second timeout and records metadata. Use [List webhook deliveries](/api-reference/catalog/webhooks/deliveries) to inspect attempts and [Test or redeliver a webhook](/api-reference/catalog/webhooks/actions) to send a test or retry a failed attempt.

## Signatures

Catalog subscription deliveries include:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
| `User-Agent` | `Lasso-Webhook/1.0` |
| `X-Lasso-Event` | Event name |
| `X-Lasso-Delivery-Id` | Stable logical delivery UUID |
| `X-Lasso-Signature` | `sha256=` plus the lowercase HMAC-SHA256 hex digest |

The create response returns the signing secret once. Verify the signature against the exact raw request body before parsing JSON.

```python
import hashlib
import hmac

def verify_lasso_signature(body: bytes, signature: str, secret: str) -> bool:
    expected = "sha256=" + hmac.new(
        secret.encode("utf-8"), body, hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(expected, signature)
```

<Warning>
  Store the signing secret when you create the endpoint. Later reads and updates never return it, and delivery-history responses never return stored payloads.
</Warning>
