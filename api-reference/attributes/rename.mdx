## Handle partial completion

This operation first renames the canonical Attribute and then migrates dependent resources. Those dependent writes are not one atomic transaction.

- `200` means every migration completed.
- `207` means the canonical rename completed but at least one dependent migration failed. Inspect `results` before continuing.
- To resume a partial rename, call the same endpoint with the same old and new keys and pass the returned `attribute.id` as `attribute_id`.
- `errors` contains stable sanitized codes. It never exposes private resource IDs or raw database errors.
