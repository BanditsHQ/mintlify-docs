description: "Enhance one or more cells in a single column. Pass one row_id for a single cell, or multiple row_ids to enhance the entire column."
openapi: "openapi.yaml POST /tables/{table_id}/enhance"
---

## Usage notes

- The table must be `completed` and unlocked.
- Send one `row_id` for one cell or up to 1,000 row IDs for one column. Duplicate IDs are processed once.
- Reference another column by its key, for example `Translate {{product_name}} to Czech`.
- This operation costs 2 credits per queued row and always returns `202`.
- `model` is a deprecated compatibility field. The service ignores it and uses its configured Gemini provider.

The worker checks credits after the `202` response. If it cannot reserve them, the affected cells move to `error` status instead of the request returning `402`. Poll `GET /tables/{table_id}/enhance/status` to track completion, then read the updated row to obtain the generated value.
