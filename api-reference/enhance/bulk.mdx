## Usage notes

Use this operation when you want to enhance several columns of one row together. It costs 0.5 credits per requested column and returns `202`.

Every column entry has its own `prompt` and may override `model`, `web_search`, or `target_language`. The row and all target columns must belong to the completed, unlocked table.
