---
title: "Get enhancement status"
description: "Check AI enhancement progress by column across a table’s rows to see which work is still running and which work has finished."
openapi: "openapi.yaml GET /tables/{table_id}/enhance/status"
---

## Usage notes

The response groups progress by column key. For each column, compare `completed + failed` with `total`. `pending` and `processing` identify work that has not reached a terminal state.

This endpoint reports counts. Use `GET /tables/{table_id}/rows/{row_id}` for values and `GET /tables/{table_id}/rows/{row_id}/traces` for AI trace details.
