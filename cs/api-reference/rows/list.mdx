## Poznámky k použití

Tento endpoint je dostupný až poté, co tabulka dosáhne stavu `completed`. Tabulka, která se stále zpracovává, vrátí `409`.

Každý řádek ukládá extrahované hodnoty v `data` podle klíče sloupce tabulky. Pro řazení použijte `sort_by` s klíčem sloupce a `sort_order` s hodnotou `asc` nebo `desc`.
