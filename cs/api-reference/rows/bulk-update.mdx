## Poznámky k použití

Tabulka musí být `completed` a nesmí být uzamčená. Aktuální handler neověřuje `column_key` proti snapshotu Product Schema. Neznámý klíč uloží do odpovídajících řádků, proto před zápisem načtěte sloupce tabulky a klíč ověřte v klientovi.

Lasso nastaví stejnou `value` na řádcích, jejichž ID patří do tabulky. Neznámá ID a ID z jiné tabulky ignoruje místo odmítnutí celého požadavku. `updated_count` vrací skutečný počet změněných řádků.
