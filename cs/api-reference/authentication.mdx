---
title: "Autentizace"
description: "Autentizujte požadavky Lasso API pomocí bearer klíče svázaného s jednou společností."
---

Každá veřejná API operace vyžaduje klíč v hlavičce `Authorization`.

```http
Authorization: Bearer lasso_vas_api_klic
```

Klíč začíná `lasso_`. Za prefixem následuje 32 náhodných bajtů zapsaných jako 64 hexadecimálních znaků.

## Vytvoření klíče

V [Lasso dashboardu](https://app.productlasso.com) otevřete **Settings** > **API Keys**. Potřebujete oprávnění **Manage API keys** (`developer.manage_api_keys`).

<Warning>
  Nezkrácený klíč se zobrazí pouze jednou. Uložte ho do správce tajemství nebo proměnné prostředí. Ztracený klíč deaktivujte a vytvořte nový.
</Warning>

## Rozsah společnosti

Každý klíč patří jedné společnosti. Server společnost odvodí z klíče a požadavek nemůže vybrat jiného tenanta.

```bash
curl --request GET \
  --url "https://app.productlasso.com/api/v1/credits/balance" \
  --header "Authorization: Bearer $LASSO_API_KEY"
```

Chybějící hlavička, nesprávný prefix, neznámý nebo deaktivovaný klíč vrací `401 unauthenticated`.
