## Atomické chování

Handler nejprve vyhodnotí dotčené zdroje a potom provede změnu klíče a podporované závislé migrace v jedné databázové operaci.

- `200` znamená, že atomické přejmenování proběhlo. Úspěšné části `results` mají `code: "ok"`, `error_count: 0` a prázdné pole `errors`.
- `409` znamená, že se neprovedla žádná částečná migrace. Detailní kódy zahrnují konflikt klíče, `rename_busy`, blokující závislosti a `stale_preview`.
- Při opakování požadavku s nejistým výsledkem předejte `attribute_id`. Handler tak najde stejný Attribute i po změně klíče.
- Většina klientů má `expected_impact_revision` vynechat. Zastaralá hodnota vrátí `409 stale_preview`.
