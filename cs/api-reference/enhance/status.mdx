## Poznámky k použití

Odpověď seskupuje průběh podle klíče sloupce. Pro každý sloupec porovnejte `completed + failed` s `total`. `pending` a `processing` označují práci, která ještě nedosáhla konečného stavu.

Tento endpoint vrací počty. Hodnoty načtěte přes `GET /tables/{table_id}/rows/{row_id}` a podrobnosti AI trace přes `GET /tables/{table_id}/rows/{row_id}/traces`.
