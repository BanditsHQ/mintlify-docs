Lasso API poskytuje přístup v rámci jedné společnosti k vyhledávání a obohacení produktů, extrakčním tabulkám, sdíleným atributům, produktovým schématům, Katalogu, webhookům, kreditům a produktové analytice.

## Základní URL

```text
https://app.productlasso.com/api/v1
```

Většina odpovědí používá JSON. Nahrávání souborů používá `multipart/form-data`. Exporty mohou vrátit JSON, CSV, XLSX nebo ZIP.

## Autentizace

Každý požadavek musí obsahovat API klíč:

```http
Authorization: Bearer lasso_vas_api_klic
```

Klíče začínají `lasso_` a zpřístupňují jednu společnost. Podrobnosti najdete v části [Autentizace](/cs/api-reference/authentication).

## API kontrakt

[OpenAPI 3.1 kontrakt](/openapi.yaml) obsahuje všech 59 veřejných operací aktuálního API včetně schémat požadavků, odpovědí a chyb. Stránky jednotlivých endpointů se generují z tohoto kontraktu.

## Úspěšné odpovědi

| Stav | Význam |
| --- | --- |
| `200` | Požadavek byl úspěšný. |
| `201` | Zdroj byl vytvořen. |
| `202` | Asynchronní zpracování bylo přijato. |
| `204` | Požadavek byl úspěšný bez těla odpovědi. |

## Stránkování

API podle zdroje používá stránkování pomocí stránky, kurzoru nebo offsetu. Ne všechny seznamy přijímají `page` a `limit`. Podrobnosti najdete v části [Stránkování](/cs/api-reference/pagination).
