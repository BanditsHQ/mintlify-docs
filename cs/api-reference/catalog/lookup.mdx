## Poznámky k použití

`key` je úložný klíč Attribute a `value` je přesná uložená hodnota. Endpoint prohledá aktivní produkty a vrátí první shodu.

Použijte ho pouze tehdy, když je vybraný Attribute ve vašem datovém modelu jedinečný. Pro obecné filtrování nebo textové hledání použijte `GET /catalog`.
