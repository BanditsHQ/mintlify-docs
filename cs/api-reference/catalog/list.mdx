## Poznámky k použití

Tento endpoint používá kurzorové stránkování, ne čísla stránek. Vrácené `next_cursor` předejte beze změny pro načtení další stránky. Hodnota `null` znamená, že je výsledek kompletní.

Objekt `attributes` obsahuje aktivní Attributes z Product Schema produktu a jeho produktové `attribute_extensions`. Výsledky zúžíte pomocí `status`, `source`, `schema_id` a `search`.
