## Uložení podpisového tajemství

Odpověď `201` obsahuje `secret` právě jednou. Před zahozením odpovědi ho bezpečně uložte. Operace seznamu a aktualizace ho už nikdy nevrátí.

- Produkční cíl musí používat veřejné HTTPS. Lasso ověřuje DNS a odmítá lokální, privátní a jinak nebezpečné cíle.
- `events` musí obsahovat alespoň jednu jedinečnou podporovanou událost.
- `name` je pro API klienty volitelné a výchozí hodnotou je hostname cíle.

Podpis ověřujte nad nezměněným tělem požadavku. Hlavičky, ověření podpisu, opakování a payloady popisuje [Webhook katalogu](/cs/api-reference/webhooks).
