## Vzor inkrementální synchronizace

1. Začněte časovým razítkem poslední úspěšné synchronizace v `since`.
2. Při procházení všech stránek přes `next_cursor` ponechte `since` beze změny.
3. Produkty aplikujte ve vráceném pořadí od nejstaršího.
4. Po úspěšném dokončení poslední stránky uložte `sync_timestamp` z první stránky jako hodnotu `since` pro další cyklus.

Tato hranice zabraňuje vynechání změn, které vzniknou během stránkování.
