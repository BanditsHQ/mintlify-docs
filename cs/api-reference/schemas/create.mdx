## Poznámky k použití

- Product Schema musí mít název a alespoň jeden sloupec.
- Existující firemní Attribute připojíte pomocí jeho `attribute_id` a `kind: attribute`. Klíč a typ musí odpovídat.
- Pomocný sloupec lokální pro tabulku vytvoříte pomocí `kind: helper` bez `attribute_id`.
- Když vynecháte obě pole identity, Lasso zachová starší chování a vytvoří nebo připojí firemní Attribute pro daný klíč sloupce.

Při pozdějším nahrazení celého pole `columns` přes `PUT /schemas/{schema_id}` zachovejte serverem přidělené `id` sloupce.
