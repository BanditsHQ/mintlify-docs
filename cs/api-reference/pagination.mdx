---
title: "Stránkování"
description: "Použijte stránku, kurzor nebo offset podle konkrétního endpointu Lasso API."
---

Lasso používá tři typy stránkování.

## Stránky

Atributy, schémata, soubory, tabulky, řádky, slovník a čerpání kreditů přijímají `page` a `limit`. Výchozí hodnoty jsou `page=1` a `limit=25`; maximální limit je `100`.

```json
{
  "data": [],
  "pagination": {
    "page": 1,
    "limit": 25,
    "total": 143
  }
}
```

## Kurzory

Seznam Katalogu vrací `next_cursor` a přijímá `page_size` nejvýše `200`. Změny Katalogu mají výchozí `page_size=100`. Aktivita produktové analytiky přijímá `cursor` a `limit` s výchozí hodnotou `25` a maximem `100`.

Kurzory předávejte beze změny. Nevytvářejte je ani nedekódujte. U `/catalog/changes` si pro další synchronizační cyklus uložte `sync_timestamp` z první stránky.

## Offset

Historie doručení webhooku přijímá `limit` a `offset`.
