## Poznámky k použití

Parametr `status` používejte pouze se surovými hodnotami vracenými API: `queued`, `queued_for_processing`, `processing`, `processing_by_worker`, `completed`, `error` nebo `cancelled`.

Odpověď používá stránkování. `locked: true` znamená, že zámek tabulky právě vlastní jiná operace. Před další změnou počkejte a požadavek opakujte.
