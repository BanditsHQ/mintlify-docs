## Formáty odpovědi

| `format` | Content-Type | Odpověď |
| --- | --- | --- |
| `csv` | `text/csv` | Soubor CSV |
| `xlsx` | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` | Sešit Excel |
| `json` | `application/json` | Pole JSON s objekty řádků |
| `images` | `application/zip` | Archiv ZIP s exportovanými obrázky |

Před exportem musí být tabulka dokončená. Parametr `columns` odešlete jako seznam klíčů sloupců oddělený čárkami. Všechny odpovědi jiné než JSON zpracujte jako bajty a při ukládání zachovejte název souboru z `Content-Disposition`.

<Warning>
  Pomocné metody TypeScript SDK pro `csv`, `xlsx` a `images` a metoda Python SDK pro `csv` se nyní pokoušejí odpověď zpracovat jako JSON. Pro tyto formáty použijte přímé HTTP. Metody Python SDK pro `xlsx` a `images` už vracejí bajty.
</Warning>

## Obsah šablon

CSV, XLSX a JSON převádějí strukturované popisy ze šablon na HTML podle nastavení exportu sloupce. Běžný export odstraňuje skripty a obsluhu událostí. CSV export Catalog má jiné chování: popisy jsou prostý text.

XLSX odmítne popis delší než 32 767 znaků v buňce místo jeho zkrácení. Pro delší obsah použijte CSV nebo JSON. Viz [Šablony obsahu](/cs/learn/content-templates) pro režimy stylování a ověření importu.
