## Poznámky k použití

`from` a `to` jsou filtry podle data. `service` přijímá přesné veřejné hodnoty uvedené ve schématu parametru. `total_used` se počítá za celé filtrované období, ne jen za aktuální stránku.

<Note>
  V Python SDK `0.2` předejte rezervovaný název dotazu jako `client.credits.usage(**{"from": "2026-08-01", "to": "2026-08-31"})`. Pomocný název `from_` se na `from` nepřekládá.
</Note>
