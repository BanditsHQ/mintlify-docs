## Význam metrik

- `from` a `to` jsou včetně krajních dat ve formátu `YYYY-MM-DD`. Maximální rozsah je 1 830 dní.
- `summary.previous_period_spent` používá stejně dlouhé období bezprostředně před `from`.
- `daily`, `by_module`, `by_service` a `by_user` představují různé agregace stejné kreditní knihy.
- `lasso.products_enhanced` je snapshot obohacených řádků v odpovídajících tabulkách, zatímco `lasso.credits_per_product` dělí kreditní výdaje Lasso ve zvoleném období tímto počtem.
- `currency_config` odráží firemní nastavení fakturační měny a ceny za kredit.

Publikované TypeScript a Python SDK tento endpoint zatím neposkytují. Volejte ho přímo přes HTTP.
