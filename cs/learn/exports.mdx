Jakmile je vaše tabulka dokončena, můžete data exportovat v několika formátech.

## Dostupné formáty

| Formát | Popis | Použití |
|---|---|---|
| **JSON** | Pole objektů řádků | Programové zpracování, API integrace |
| **CSV** | Soubor oddělený středníky | Import do tabulek, analýza dat |
| **XLSX** | Excel tabulka | Obchodní uživatelé, reporting |
| **Images** | ZIP archiv všech obrázků | Správa médií, knihovny médií |

## Export dat

SDK helper pro JSON vrací parsovaná data. V TypeScript SDK v0.2 načítejte CSV, XLSX a ZIP obrázků přímo z endpointu, abyste mohli přečíst nezpracované tělo odpovědi.

<CodeGroup>
```typescript TypeScript
import { writeFile } from "node:fs/promises";

// JSON returns parsed data through the SDK.
const data = await client.export.json("d2b3dbe0-c77d-40d8-a5d2-480722489c64");

async function fetchExport(format: "csv" | "xlsx" | "images") {
  const url = new URL(
    "https://app.productlasso.com/api/v1/tables/d2b3dbe0-c77d-40d8-a5d2-480722489c64/export",
  );
  url.searchParams.set("format", format);

  const response = await fetch(url, {
    headers: { Authorization: `Bearer ${process.env.LASSO_API_KEY}` },
  });
  if (!response.ok) throw new Error(await response.text());
  return response;
}

const csv = await (await fetchExport("csv")).text();
const xlsx = Buffer.from(await (await fetchExport("xlsx")).arrayBuffer());
const images = Buffer.from(await (await fetchExport("images")).arrayBuffer());

await writeFile("export.xlsx", xlsx);
await writeFile("images.zip", images);
```

```python Python
import httpx
import os

# JSON -- returns list of dicts
data = client.export.json("d2b3dbe0-c77d-40d8-a5d2-480722489c64")

# Fetch CSV as text from the endpoint.
response = httpx.get(
    "https://app.productlasso.com/api/v1/tables/d2b3dbe0-c77d-40d8-a5d2-480722489c64/export",
    params={"format": "csv"},
    headers={"Authorization": f"Bearer {os.environ['LASSO_API_KEY']}"},
)
response.raise_for_status()
csv = response.text

# XLSX -- save directly to file
client.export.xlsx("d2b3dbe0-c77d-40d8-a5d2-480722489c64", path="export.xlsx")

# Images -- save ZIP to file
client.export.images("d2b3dbe0-c77d-40d8-a5d2-480722489c64", path="images.zip")
```
</CodeGroup>

## Výběr sloupců

Ve výchozím nastavení se exportují všechny sloupce. Pro export pouze konkrétních sloupců předejte seznam klíčů sloupců oddělených čárkou:

<CodeGroup>
```typescript TypeScript
const data = await client.export.json("d2b3dbe0-c77d-40d8-a5d2-480722489c64", {
  columns: "product_name,price,image_url",
});
```

```python Python
data = client.export.json("d2b3dbe0-c77d-40d8-a5d2-480722489c64", columns="product_name,price,image_url")
```
</CodeGroup>

## Integrace s Pandas (Python)

Python SDK obsahuje pomocnou funkci pro načtení všech řádků jako pandas DataFrame:

```python
df = client.tables.results_as_dataframe("d2b3dbe0-c77d-40d8-a5d2-480722489c64")

# Filter, analyze, or export further
expensive = df[df["price"] > 100]
df.to_csv("products.csv", index=False)
```

Tato funkce automaticky načte všechny stránky a vrátí DataFrame připravený k použití.
