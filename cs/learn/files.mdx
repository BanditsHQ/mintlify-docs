---
title: 'Nahrávání souborů'
description: 'Nahrajte zdrojové soubory pro extrakci dat.'
---

Lasso přijímá řadu formátů souborů jako zdrojová data pro extrakci. Nejprve nahrajte soubory a poté na ně odkazujte pomocí ID při vytváření tabulky.

## Podporované formáty

| Formát | Přípony | Poznámky |
|---|---|---|
| PDF | `.pdf` | Podporovány jsou jak skenované, tak textové PDF soubory. |
| Tabulky | `.xlsx`, `.xls`, `.xlsm`, `.csv` | Každý list nebo soubor je parsován pro data o produktech. |
| Obrázky | `.jpg`, `.jpeg`, `.png`, `.webp` | OCR extrahuje text z obrázků. |
| Dokumenty | `.docx`, `.pptx` | Dokumenty Word a PowerPoint jsou parsovány pro obsah. |
| Text a značkování | `.txt`, `.xml`, `.html`, `.htm` | Textový obsah se dekóduje a parsuje. |

## Postup nahrávání

<Steps>
  <Step title="Nahrajte soubor">
    Odešlete soubor jako `multipart/form-data` na `POST /files`. Endpoint pro nahrání přijímá soubory do 1 GB.
  </Step>
  <Step title="Získejte ID souboru">
    Odpověď obsahuje pole `id`. Uložte si ho pro další krok.
  </Step>
  <Step title="Vytvořte tabulku">
    Předejte ID souboru v poli `file_ids` při vytváření tabulky.
  </Step>
</Steps>

## Limity extrakce

Při vytváření tabulky platí přísnější limity zdrojů než při samotném nahrání:

| Typ zdroje | Maximální velikost |
|---|---:|
| PPTX | 20 MB |
| DOCX | 50 MB |
| XML, HTML, HTM nebo TXT | 64 MB |
| JPG, JPEG, PNG nebo WebP | 100 MB |
| Ostatní typy souborů | 256 MB |
| Všechny vybrané soubory dohromady | 512 MB |

API odmítne duplicitní názvy zdrojových souborů v jednom požadavku na tabulku.

## Příklad

<CodeGroup>
```typescript TypeScript
const file = new File([buffer], "catalog.pdf", { type: "application/pdf" });
const uploaded = await client.files.upload(file, "catalog.pdf");

const table = await client.tables.create({
  schema_id: "9e1c77dd-8f10-41ca-bfe8-e672b89692d1",
  name: "My Catalog",
  file_ids: [uploaded.id],
});
```

```python Python
uploaded = client.files.upload("/path/to/catalog.pdf")

table = client.tables.create(
    schema_id="9e1c77dd-8f10-41ca-bfe8-e672b89692d1",
    name="My Catalog",
    file_ids=[uploaded["id"]],
)
```
</CodeGroup>

## Alternativní zdroje

Pokud nechcete nahrávat soubor, předejte surový text v `source_text`. Vzdálený soubor nejprve stáhněte a nahrajte přes `POST /files`; přímé použití `file_urls` extrakční worker nepodporuje.

## Správa souborů

Soubory lze zobrazit a smazat prostřednictvím [Files API](/cs/api-reference/files/list). Smazání souboru neovlivní tabulky, které z něj již byly vytvořeny.
