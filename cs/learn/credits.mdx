Lasso používá kreditový systém pro operace extrakce a obohacení.

## Co spotřebovává kredity

| Operace | Náklady v kreditech |
|---|---|
| **Extrakce tabulky** | Liší se podle velikosti souboru a složitosti |
| **Obohacení jedné buňky** | ~2 kredity za buňku |
| **Hromadné obohacení, běžný sloupec** | ~0,5 kreditu za sloupec |
| **Hromadné obohacení, obrázek Gallery Max** | 16 kreditů za sloupec |

Odpověď enhancementu obsahuje odhad. Veřejný bulk handler aktuálně počítá každý sloupec jako 0,5 kreditu i tehdy, když snapshot tabulky nastavuje obrázkový sloupec Gallery Max. Pro takový sloupec použijte sazbu výše.

## Kontrola zůstatku

<CodeGroup>
```typescript TypeScript
const balance = await client.credits.balance();
console.log(`${balance.balance} credits remaining`);
```

```python Python
balance = client.credits.balance()
print(f"{balance['balance']} credits remaining")
```
</CodeGroup>

## Sledování využití

Zobrazte historii kreditových transakcí s volitelnými filtry:

<CodeGroup>
```typescript TypeScript
const usage = await client.credits.usage({
  from: "2025-01-01T00:00:00Z",
  to: "2025-03-31T23:59:59Z",
  service: "ai_field",
});

console.log(`Total used: ${usage.total_used} credits`);
```

```python Python
usage = client.credits.usage(**{
    "from": "2025-01-01T00:00:00Z",
    "to": "2025-03-31T23:59:59Z",
    "service": "ai_field",
})

print(f"Total used: {usage['total_used']} credits")
```
</CodeGroup>

## Agregované statistiky

`GET /credits/stats` vrací denní přehledy a souhrny podle modulu, služby, uživatele a tabulky Lasso za inkluzivní období `YYYY-MM-DD`. Zahrnuje také stejně dlouhé předchozí období, měsíční příděl a nakonfigurované náklady na kredit. Maximální období je 1 830 dní.

```bash
curl --request GET \
  --url "https://app.productlasso.com/api/v1/credits/stats?from=2026-08-01&to=2026-08-31" \
  --header "Authorization: Bearer $LASSO_API_KEY"
```

## Nedostatečné kredity

Veřejné handlery aktuálně nevracejí nedostatek kreditů jednotně jako `402`:

- Synchronní Search a Enrich vrátí HTTP `200` s polem `error` a bez výsledků.
- Enhancement vrátí `202` před rezervací kreditů. Dotčené buňky později přejdou do stavu `error`.

Před velkou operací zkontrolujte `GET /credits/balance` a sledujte výsledek operace nebo stav enhancementu.
