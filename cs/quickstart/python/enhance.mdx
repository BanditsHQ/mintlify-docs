## Obohacení sloupce

Použijte AI ke generování nebo obohacení hodnot pro konkrétní sloupec ve vybraných řádcích.

```python
rows = client.tables.rows("d2b3dbe0-c77d-40d8-a5d2-480722489c64", limit=100)

job = client.enhance.cells(
    "d2b3dbe0-c77d-40d8-a5d2-480722489c64",
    row_ids=[r["id"] for r in rows["data"]],
    column_key="description",
    prompt="Write a compelling product description from {{product_name}} and {{price}}.",
    web_search=True,
)

print(job["id"])                 # "b672c561-236d-47e4-b9ec-7c4219454aa8"
print(job["status"])             # "queued"
print(job["estimated_credits"])  # 84
```

## Kontrola průběhu obohacení

```python
status = client.enhance.status("d2b3dbe0-c77d-40d8-a5d2-480722489c64")

for column, stats in status["columns"].items():
    print(f"{column}: {stats['completed']}/{stats['total']} done")
```

## Obohacení více sloupců najednou

Obohaťte několik sloupců jednoho řádku v jednom požadavku:

```python
client.enhance.bulk(
    "d2b3dbe0-c77d-40d8-a5d2-480722489c64",
    row_id="83ba2c61-8592-4614-ac46-10f43580dfb8",
    columns=[
        {"key": "description", "prompt": "Write a product description from {{product_name}} and {{price}}."},
        {"key": "seo_title", "prompt": "Generate an SEO-optimized title from {{product_name}}."},
        {"key": "description_de", "prompt": "Translate {{description}} to German."},
    ],
)
```

## Zrušení obohacení

```python
result = client.enhance.cancel("d2b3dbe0-c77d-40d8-a5d2-480722489c64")
print(result["cancelled_count"])
```
