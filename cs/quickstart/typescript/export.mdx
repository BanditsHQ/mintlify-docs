## Export jako JSON

```typescript
const data = await client.export.json("d2b3dbe0-c77d-40d8-a5d2-480722489c64");
console.log(data); // [{ product_name: "...", price: 29.99 }, ...]
```

## Export jako CSV

```typescript
const response = await fetch(
  "https://app.productlasso.com/api/v1/tables/d2b3dbe0-c77d-40d8-a5d2-480722489c64/export?format=csv",
  { headers: { Authorization: `Bearer ${process.env.LASSO_API_KEY}` } },
);
if (!response.ok) throw new Error(await response.text());
const csv = await response.text();
```

## Export jako XLSX

```typescript
import { writeFile } from "node:fs/promises";

const response = await fetch(
  "https://app.productlasso.com/api/v1/tables/d2b3dbe0-c77d-40d8-a5d2-480722489c64/export?format=xlsx",
  { headers: { Authorization: `Bearer ${process.env.LASSO_API_KEY}` } },
);
if (!response.ok) throw new Error(await response.text());
await writeFile("export.xlsx", Buffer.from(await response.arrayBuffer()));
```

## Export obrázků

Stáhněte všechny obrázky ze sloupců s obrázky jako ZIP:

```typescript
import { writeFile } from "node:fs/promises";

const response = await fetch(
  "https://app.productlasso.com/api/v1/tables/d2b3dbe0-c77d-40d8-a5d2-480722489c64/export?format=images",
  { headers: { Authorization: `Bearer ${process.env.LASSO_API_KEY}` } },
);
if (!response.ok) throw new Error(await response.text());
await writeFile("images.zip", Buffer.from(await response.arrayBuffer()));
```

## Výběr konkrétních sloupců

```typescript
const data = await client.export.json("d2b3dbe0-c77d-40d8-a5d2-480722489c64", {
  columns: "product_name,price,image_url",
});
```
